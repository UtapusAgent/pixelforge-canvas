## Use Case

As a user annotating or creating artwork, I want to draw and erase directly on the canvas with configurable brush settings.

## Details

- Provide brush and eraser tools.
- Create or activate a drawing layer before drawing.
- Support brush size, color, opacity, and hardness.
- Support undo for strokes.
- Support pressure-sensitive input when available.
- Keep pointer feedback smooth on large canvases.

## Acceptance Criteria

- Brush strokes appear on an editable drawing layer.
- Brush size, color, and opacity are user-controllable.
- Eraser removes drawing content.
- Stroke operations are undoable.
- Drawing layers participate in layer visibility, lock state, z-order, and export.
